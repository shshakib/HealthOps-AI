# v0.1.0 — Local prototype

HealthOps AI is a runnable clinical-trial prescreening workbench using synthetic
patient data and dated public study records.

- React dashboard for patient records, screening evidence, trial interpretations,
  human decisions, and review history.
- Reproducible Synthea generation/import with HAPI FHIR and PostgreSQL.
- Versioned ClinicalTrials.gov snapshots and a separate rule-review workflow.
- Evidence assistant with Ollama, OpenAI, Claude, and Gemini adapters, server-session
  API-key settings, and an explicit evidence-only fallback.
- Docker setup, MIT license, provenance notices, and GitHub Actions for Python,
  dashboard build/browser tests, and secret scanning.

Verified locally: 118 Python tests and six browser workflows. CI uses handcrafted
FHIR stand-ins and fake provider credentials, so it requires no Docker data or paid
model calls. Real HAPI integration has separate documented local checks. Live model
quality and account access still need validation with the user's chosen provider.

This release is intended for local synthetic-data demonstrations. See the README
for current capabilities, setup instructions, and limitations.
